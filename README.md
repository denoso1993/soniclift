# SoundBlast

Boost de áudio por dispositivo para Windows — **APO nativo**, sem driver ou
dispositivo virtual.

## Download

Baixe o instalador mais recente em **Releases** (`SoundBlastSetup-*.exe`) e
execute como Administrador. Ele instala o app, o APO, cria atalhos e um
desinstalador que remove tarefa de logon, vínculos e a DLL do System32.

## Recursos

- Ganho de **-20 dB a +30 dB** com limiter sempre ativo, aplicado ao vivo.
- Aplica em **todos os dispositivos reais ativos** por padrão.
- **Isolar por dispositivo** com lista sem duplicados (agrupa perfis do mesmo
  aparelho Bluetooth).
- **Iniciar com o Windows**; minimiza para a bandeja com aviso.
- Ícone próprio, instância única e idiomas **Português, English, Español**.
- O Windows continua trocando de fone/caixa/USB normalmente.
