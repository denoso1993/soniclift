Features

Simple on the surface. Serious under the hood.

One switch and one slider for everyday use. A full 10-band EQ when you want to go deeper.

Up to +30 dB, tamed

Push quiet laptop speakers and Bluetooth boxes further, with a limiter that keeps peaks under control instead of clipping.

10-band equalizer

Shape 31 Hz to 16 kHz with six presets: Flat, Music, Gaming, Bass, Voice and Movie. Save and share EQ profiles.

Bass, Surround and Clarity

Three friendly sliders for quick tuning: low-end weight, stereo width and presence in the upper mids.

Automatic headroom

Boost the EQ without harsh clipping. SonicLift compensates the preamp as you raise the bands.

Device-native

Windows keeps switching between headset, Bluetooth, USB and HDMI. The effect follows the active real device.

Tray and autostart

Single instance, starts with Windows, closes to the tray and keeps processing in the background.

Import and export EQ

Back up your tuning to a small file, move it to another PC, or share it with a friend.

Three languages

English by default, with complete Portuguese and Spanish translations in the app and installer.

Isolate by device

Apply the boost only where you want, with a de-duplicated list that groups Bluetooth profiles of the same device.

How it works

Inside the device. Not in front of it.

No virtual sound card, no extra device to select, no driver layer in the middle.

Install

On first launch, SonicLift registers the APO and binds it to your output endpoint through Windows FxProperties.

Tune

Set the gain, EQ, bass, surround and clarity. The UI publishes changes live through shared memory.

Keep listening

audiodg.exe runs the effect inside the device pipeline. Change devices and the sound follows.

Compatibility

Works with shared-mode audio on real devices.

Games, browsers, music, system sounds, calls and several apps at once.

  • Applies to all active real devices by default: USB, Bluetooth, HDMI and S/PDIF.
  • Follows Windows device switching; no virtual device to select.
  • Live gain: the slider applies immediately, without restarting audio.
  • Ignores virtual devices such as FxSound on purpose.
  • Settings survive the UI being closed; the APO keeps running.
  • WASAPI exclusive / ASIO apps bypass any APO, not only SonicLift.
  • DRM / protected audio may refuse audio because the installer sets DisableProtectedAudioDG=1.
  • Apps manually routed to a virtual device bypass the APO. Keep them on Default or a real device.
  • The Windows Volume Mixer only lists apps with an active audio session.

FAQ

Straight answers.

Is it safe?

The code is proprietary, but it is transparent about what it changes. Every registry key, file and scheduled task is documented in SECURITY.md. There is no network access, no telemetry and no data collection. Verify the installer hash before running.

Why does SmartScreen warn?

The binaries are not code-signed yet, so Windows shows the standard warning. The installer is distributed only through the official GitHub release, with a published SHA-256 hash.

Does it work with every app?

It processes shared-mode audio on real output devices: games, browsers, music, system sounds and communication apps. Apps using WASAPI exclusive or ASIO, and apps routed to a virtual device, are the exceptions.

Does it have an equalizer?

Yes. A 10-band EQ from 31 Hz to 16 kHz with six presets, plus Bass, Surround and Clarity sliders and automatic headroom. You can also import and export EQ profiles.

Can I use it together with FxSound?

Technically yes, but avoid routing apps to FxSound's virtual device. Since SonicLift replaces that role, uninstalling FxSound is recommended.

Does it survive Windows updates?

Windows updates and driver installs can reset FxProperties. If audio stops being processed, open SonicLift and reapply the APO.

Is it free?

Free for personal use, with an optional donation. Commercial use requires a separate license.

Why the new name?

SonicLift is the new name of SoundBlast. It is the same app with a clearer identity. On first run, existing settings, EQ profiles and device bindings are migrated automatically.
